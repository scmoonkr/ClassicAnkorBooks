# KRIN Classic 앵커도서 제작 지침
> 2026-10-05 통합 개정 (초판 2026-04-23) | L1~L4 레벨별 텍스트 제작 + DB 등록 전 과정 가이드
> 앵커도서 제작의 기준 문서다. `ankors/GUIDE.md` · `ankor-prompt.md` 는 이전 방식이라 KRIN 목표 범위와 파일 형식이 다르다.
> 기존 `ANCHOR_GUIDE.md` 와 레벨별 작성 스킬(`krin-l1-writing` ~ `krin-l4-writing`)을 이 문서 하나로 통합했다. 레벨별 작성 규칙은 4장에 있다.

---

## 1. 앵커도서란

고전 문학을 KRIN L1~L4 레벨에 맞게 **재작성(rewrite)** 한 콘텐츠.
동일한 작품이 4개 레벨로 존재하며, 각 레벨은 독립된 챕터 레코드로 저장된다.

- 원전 출처: Project Gutenberg(서양), 위키문헌·공유마당(한국)
- 목표: 같은 이야기를 레벨에 맞는 어휘·문장·분량으로 재작성
- **번역이나 요약이 아님** — KRIN 범위에 맞는 독립 텍스트를 새로 씀

---

## 2. 제작 과정

> 설계 → 본문 → 검증 → 부가 콘텐츠 순서로 나눈다.
> 본문(story)이 KRIN 검증을 통과한 뒤에 intro · 나눔 · 토론 · 문제해결 · 퀴즈를 만든다 (모두 본문에 의존하기 때문).

```text
① 설계      원전 확보 → LLM: 목차 · 분량 배분 · 목차별 장면(scene_list)        → 사람 확인
② 본문      LLM: 장면별 L4 작성 → L4 를 참조해 L3 · L2 · L1 작성
③ 등록(1차)  챕터 파일 저장 → anchor DB 등록 (목차 + 본문, status=draft)
④ 검증      규칙 검사 + KRIN 분석 → 벗어난 챕터·레벨만 ②로 돌아가 다시 작성 → ③
⑤ 부가      LLM: intro_static · sharing · debate · problem_solve · quiz 작성   → 정답 검증
⑥ 등록(2차)  anchor DB 등록 → 교사 검수 → reviewed=true
```

### ① 설계 — 목차 · 분량 배분 · 장면

- **입력**: 원전 텍스트 (Project Gutenberg / 위키문헌 · 공유마당, `ankors/text/`). 원전 없이 LLM 기억만으로 쓰지 않는다 — 줄거리를 지어낸다
- **산출**
  - 목차: 챕터 번호 · 제목 (제목은 내용을 암시하되 결말을 드러내지 않는다)
  - 분량 배분: 챕터별 원전 범위와 레벨별 목표 분량 (3장 표)
  - 장면 목록 `scene_list`: 챕터마다 3~7개 (5장)
- 장면 목록은 **네 레벨이 함께 쓰는 기준**이다. 어느 레벨이든 이 장면을 빠뜨리거나 새 장면을 만들지 않는다
- 등장인물 이름 · 지명 표기를 여기서 정한다 (모든 레벨 동일)
- **사람 확인**: 목차와 장면이 틀리면 뒤 단계를 전부 다시 해야 한다. 본문을 쓰기 전에 확인한다

### ② 본문 — L4 먼저, 이어서 L3 · L2 · L1

- **L4**: 장면 목록과 원전을 보고 장면별로 쓴다. 원전의 문체 · 맥락에 가장 가깝게 (4장 L4)
- **L3 · L2 · L1**: 장면 목록을 기준으로 삼고 **L4 는 내용 참고용**으로 쓴다
  - L4 문장을 줄이거나 쉬운 말로 바꿔 끼우지 않는다 — 긴 문장 구조와 어려운 어휘가 그대로 남는다
  - 같은 장면을 그 레벨의 어휘 · 문장 · 분량 기준(3장 · 4장)으로 **새로 쓴다**
  - 레벨이 내려갈수록 장면의 세부(심리 · 상징 · 배경 설명)를 덜어 내고 행동과 대화를 남긴다
- 레벨별 작성 규칙은 4장을 따른다
- 챕터 1개 = 파일 1개, 레벨마다 따로 (6장 파일 형식)

### ③ 등록(1차) — 목차 + 본문

```bash
# ankors/ 폴더 → anchor_books / anchor_chapters upsert + KRIN 분석까지 한 번에
npm --prefix packages/server run seed:anchor -- --book <book_id>
npm --prefix packages/server run seed:anchor -- --book <book_id> --dry-run      # 쓰기 없이 확인
npm --prefix packages/server run seed:anchor -- --book <book_id> --no-analyze   # 등록만
```

- 이 단계의 파일은 `status: "draft"`, `reviewed: false`
- KRIN 분석기는 DB(`anchor_chapters`)를 읽는다 — 그래서 분석 전에 등록이 먼저다

> **도구 보완 필요**: 지금 `seed:anchor` 는 `scene_list` · `quiz` · `intro_static.reading_point` 가 모두 있는 파일만 받는다.
> 1차 등록(목차 + 본문만)을 하려면 이 조건을 `scene_list` + `content` 로 낮춰야 한다.
> 또 서버는 `status` 로 걸러 주지 않으므로 draft 본문도 Reader 앱에 보인다 — 검수 전 책을 숨기려면 서버에서 걸러야 한다.

### ④ 검증 — 규칙 검사 + KRIN 분석, 벗어나면 다시 작성

```bash
npm run anchor:analyze --workspace=packages/modeling            # 미분석 챕터만
npm run anchor:analyze:force --workspace=packages/modeling      # 전체 재분석
# 리포트: ankor/{책제목} {레벨}/report.md
```

| 검사 | 기준 | 벗어나면 |
|---|---|---|
| 분량 · 문장 길이 | 3장 표 (레벨별 글자 수 · 어절 수) | 해당 챕터 다시 작성 |
| KRIN 범위 | L1 430~560 · L2 520~680 · L3 650~820 · L4 800~1050 | 리포트의 편중 요소대로 수정 |
| 레벨 순서 | 같은 챕터에서 L1 < L2 < L3 < L4 | 뒤집힌 레벨을 다시 작성 |
| 장면 일치 | 네 레벨이 scene_list 의 장면을 모두 다룸 | 빠진 장면 보완 |

- **벗어난 챕터 · 레벨만** 다시 쓴다. 전체를 다시 돌리면 통과했던 챕터까지 바뀌어 다시 검증해야 한다
- 다시 쓸 때는 리포트 내용(편중 요소 · 근거 단어와 문장 · 처방)을 LLM 에 그대로 준다
  - 어휘 ▲ → 쉬운 어휘로 교체 / 문장 ▲ → 문장 분리, 종속절 축소 / 개념 ▲ → 구체적 장면으로
  - 하단 이탈(너무 쉬움)이면 반대로: 그 레벨의 교과 어휘 · 복문 · 내면 묘사를 늘린다
- 한 챕터에 **최대 3회**까지. 그래도 벗어나면 사람이 고친다 (평균 자체가 벗어나면 엔진 보정 문제일 수 있다)
- 다시 쓴 뒤에는 ③으로 돌아가 등록 · 재분석한다

### ⑤ 부가 콘텐츠 — 본문이 확정된 뒤

본문이 ④를 통과한 챕터만 대상으로 한다. 본문이 바뀌면 이 단계 산출물도 다시 만든다.

| 필드 | 내용 | 기준 |
|---|---|---|
| `intro_static` | 읽기 전 안내 (요약 · 인물 · 배경 · 읽기 포인트 · 흥미 유발 질문 · 미리 말하면 안 되는 것) | 7장 |
| `sharing` | 나눔 — 인용 문장 + 질문 | 8장 |
| `debate` | 토론 논제 | 8장 |
| `problem_solve` | 문제 해결 과제 | 8장 |
| `quiz` | 미니게임 문항 | 9장 |

- **레벨마다 따로 만든다.** 인용 문장과 퀴즈 정답은 그 레벨 본문에 실제로 있어야 한다
  (L4 본문으로 만든 문제는 L1 본문에 없는 내용일 수 있다)
- **정답 검증**: 만든 뒤 LLM 에 본문과 문항을 함께 주고 "본문만 보고 답할 수 있는가, 정답이 하나인가"를 확인시킨다.
  인용 문장(`anchor_quotes`)은 본문에 글자 그대로 있는지 기계적으로 대조한다

### ⑥ 등록(2차) · 검수

```bash
npm --prefix packages/server run seed:anchor -- --book <book_id> --no-analyze
```

- 10장 체크리스트로 확인 → 교사 · 독서 전문가 검토 → `reviewed: true`
- 이후 본문을 고치면 ④(검증)와 ⑤(부가 콘텐츠)를 그 챕터에 대해 다시 한다

## 4. 레벨별 텍스트 작성 기준

### 4.0 공통 규칙 (전 레벨)

**독자 이미지 고정** — 쓰기 전에 그 레벨 독자가 읽는 장면을 상상한다. 각 레벨 절의 첫 항목이다.

**작성 절차 (공통)**
1. **원전을 덮고** 줄거리 · 핵심 감정 · scene_list 만 머릿속에 넣는다 (L4 는 원전의 문체 · 어조도 파악)
2. 그 레벨 독자에게 읽어 주는 느낌으로 **처음부터 새로 쓴다**
3. 다 쓴 뒤 **소리 내어 읽는다** — 막히는 곳이 고칠 곳이다
4. 레벨별 점검(어절 수 · 비율 · 심리 묘사 등)을 한다
5. 레벨별 체크리스트로 마무리한다

**출력 형식 및 장면 구분**
- 장면 제목은 출력하지 않는다. `장면 1.`, `장면 2.` 같은 표기를 본문에 넣지 않는다
- 장면의 사건과 내용은 생략하지 않고 본문에 자연스럽게 이어 쓴다
- 장면이 바뀌는 지점에는 빈 줄을 한 줄 넣어 경계를 표시한다
- 장 제목 다음에도 빈 줄을 한 줄 둔다
- 출력에는 장 제목과 본문만 포함한다. 작성 지침 · 장면 목록 · 해설 · 주석은 출력하지 않는다

**레벨 경계** — 한 레벨에서 쓴 기법이 다음 레벨에서 어떻게 달라지는지 각 절에 "경계"로 적었다. 아래 예문은 같은 장면(백설공주)을 네 레벨로 쓴 것이다.

---

### 4.1 L1 — 초등 저학년 (KRIN 430~560 · 500~800자)

**독자 이미지**: 초등 2학년 어린이가 혼자 소리 내어 읽는다. 막히면 안 되고, 모르는 단어가 나오면 안 되고, 지루하면 안 된다.

**어휘**

| 규칙 | 예시 |
|------|------|
| 1~2음절 생활 어휘 위주 | 집, 밥, 길, 달리다, 예쁘다 |
| 한자어 → 쉬운 말로 교체 | 도착했다 → 왔다 / 출발했다 → 떠났다 / 결심했다 → 마음먹었다 |
| 외래어 최소화 | 드레스 → 옷 (맥락상 불가피한 경우만) |
| 문단당 모르는 단어 1개 이하 | 새 단어는 바로 뒤 문장에서 뜻이 드러나게 |

**문장**
- **어절 7개 이하** (필수), 주어 + 서술어 단문 위주
- 복문은 챕터 전체에 2~3개 이하, 한 문장에 접속사 1개까지 ("그래서", "그런데", "하지만")
- 시제는 전체 과거형 통일 (현재형 혼용 금지), 어미는 "~했어요"
- 어절 초과 문장은 나눈다
  ```
  ❌ 마녀는 세상에서 자신이 가장 아름답다고 생각했기 때문에 화가 많이 났어요.
  ✅ 마녀는 자신이 제일 예쁘다고 생각했어요. 그래서 화가 많이 났어요.
  ```

**구조**
- 1문단 = 3~5문장, 1챕터 = 5~8문단
- 각 문단은 **하나의 행동이나 사건**만 담는다
- 대화문이 전체의 **30% 이상** (독자가 캐릭터와 친해지게)

**대화문** — 서술보다 한 단계 더 쉽게, 그 나이 아이가 말할 법한 어투로.
```
❌ "나는 지금 매우 화가 난 상태야."      ✅ "나 너무 화났어!"
❌ "당신은 어디로 가려고 합니까?"        ✅ "어디 가?"
```

**금지 표현**

| 금지 패턴 | 이유 | 대체 |
|-----------|------|------|
| "~되어졌다", "~하게 되었다" (피동 중첩 · 피동형 남용) | 어색함 | 능동형으로 |
| "~에 대한", "~으로 인하여" (관료적 표현) | 어려움 | 쉬운 말로 풀기 |
| "비통함", "허탈감", "숭고한" (추상 감정 명사) | 이해 어려움 | 행동으로 표현 |
| 관형절 중첩 ("하얀 눈이 덮인 조용한 숲속의 오두막") | 구조 복잡 | 문장 분리 |
| "~하였습니다" | 고어투 | "~했어요" |

**추상 감정 → 행동으로**
```
❌ 백설공주는 슬픔을 느꼈다.        ✅ 백설공주는 눈물이 났어요.
❌ 그는 공포에 휩싸였다.            ✅ 그는 너무 무서워서 그 자리에 멈췄어요.
```

**체크리스트**
- [ ] 챕터 분량 500~800자
- [ ] 모든 문장 어절 7개 이하
- [ ] 한자어/외래어 최소화
- [ ] 대화문 30% 이상
- [ ] 피동형 없음
- [ ] 추상 감정 → 행동으로 표현
- [ ] 시제 과거형 통일
- [ ] KRIN 점수 430~560 범위
- [ ] 초등 1~3학년이 혼자 읽을 수 있는 수준

**예시 (백설공주 L1)**
```
마녀가 마법 거울 앞에 섰어요.
"세상에서 제일 예쁜 사람이 누구야?"
거울이 대답했어요.
"그건 백설공주예요."
마녀는 화가 났어요. 그래서 독이 든 사과를 만들었어요.
백설공주를 없애버리고 싶었거든요.
```
- 최장 문장 "그래서 독이 든 사과를 만들었어요." → 6어절 ✅ / 대화문 포함 ✅ / 한자어 없음 ✅ / 감정(화남)을 행동(사과 만들기)으로 연결 ✅

### 4.2 L2 — 초등 고학년 (KRIN 520~680 · 900~1,300자)

**독자 이미지**: 초등 5학년이 혼자 책을 읽는다. 어느 정도 어려운 단어는 문맥으로 이해하고, 감정과 인과 관계를 따라간다. 복잡한 구조나 추상적인 표현은 아직 부담스럽다.

**어휘**

| 규칙 | 예시 |
|------|------|
| 초등 4~6학년 교과서 수준 | 도착, 출발, 결정, 비교, 탐험 |
| 쉬운 한자어 도입 허용 | 결심, 용기, 위험, 신비롭다 |
| 새 어휘는 문맥에서 뜻 추론 가능하게 | "신비로운 물건 — 무엇이든 진실만 말하는 거울이었습니다" |
| 문단당 새 어휘 2~3개까지 | 초과 시 다음 문단으로 분산 |

**L1과의 차이**: 쉬운 한자어, 인과 관계 명시, 간단한 감정 묘사, 직유가 추가된다.
**L3로 넘어가지 않기**: 중학 교과 추상어(질투, 허영, 운명, 집착) · 복잡한 한자어(야망, 숭고, 비통)는 L3 이상에서. 고어투("~하였나이다", "~하옵니다")는 절대 금지.

**문장**
- **어절 10개 이하** (필수), 단문 + 복문 혼합 = **6:4**
- 접속사 다양하게: 그러나, 하지만, 그래서, 왜냐하면, 그러므로
- 인과 관계 최소 1회 명시: "왜냐하면 ~이기 때문이었습니다"
- 어절 초과 문장은 나눈다
  ```
  ❌ 왕비는 세상에서 자신이 가장 아름다워야 한다고 믿었기 때문에 백설공주를 없애기로 결심했습니다.
  ✅ 왕비는 자신이 세상에서 가장 아름다워야 한다고 믿었습니다.
     그래서 백설공주를 없애기로 결심했습니다.
  ```

**서술**
- 행동 묘사 + **간단한 감정** 함께. 내면 심리는 짧고 단순하게 (L3처럼 길게 쓰지 않는다)
- 시간 · 장소 전환 명시: "다음 날 아침", "숲 깊숙이 들어가자"
- 직유 1~2개 허용 ("~처럼", "~같이"), 은유는 지양

```
감정 묘사 수준 — L1: 마녀는 화가 났어요.
                 L2: 왕비의 얼굴이 굳어졌습니다. 가슴속에서 질투심이 끓어올랐습니다.
                 L3: (심리 묘사 + 복선 포함)
```

**구조**
- 1문단 = 4~6문장, 1챕터 = 6~9문단
- 장면 전환 시 빈 줄 + 시간/장소 표시로 시작
- 챕터 끝: 다음 챕터를 궁금하게 하는 문장 1개

**대화문** — 대화 + 행동 묘사를 함께, 대화 태그 다양하게("말했습니다", "속삭였습니다", "외쳤습니다"), 비율 전체의 20~30%.
```
❌ "가겠습니다." 그가 말했습니다.
✅ "그럼 저도 함께 가겠습니다." 소년은 두 주먹을 꽉 쥐며 말했습니다.
```

**체크리스트**
- [ ] 챕터 분량 900~1,300자
- [ ] 모든 문장 어절 10개 이하
- [ ] 단문:복문 = 6:4
- [ ] 인과 관계 최소 1회 명시
- [ ] 감정 묘사 포함 (짧고 직접적으로)
- [ ] 시간/장소 전환 표시
- [ ] 직유 1~2개 (은유 지양)
- [ ] KRIN 점수 520~680 범위
- [ ] 초등 4~6학년 교과 어휘 수준

**예시 (백설공주 L2)**
```
왕비는 마법 거울 앞에 섰습니다. 거울은 언제나 진실만을 말하는 신비로운 물건이었습니다.
"거울아, 세상에서 가장 아름다운 사람이 누구냐?"
거울이 대답했습니다. "왕비님, 그것은 백설공주입니다."
왕비의 얼굴이 굳어졌습니다. 그녀는 백설공주를 없애기로 결심했습니다.
왜냐하면 자신이 세상에서 가장 아름다워야 한다고 믿었기 때문입니다.
```
- 최장 문장 9어절 ✅ / 인과 관계 "왜냐하면 ~기 때문입니다" ✅ / 새 어휘 "신비로운"은 앞 문장에서 뜻 설명 ✅ / 감정은 "얼굴이 굳어졌습니다"(행동)로 표현 ✅

### 4.3 L3 — 중학생 (KRIN 650~820 · 1,400~2,000자)

**독자 이미지**: 중학교 2학년 국어 시간에 읽는 단편소설. 캐릭터의 심리가 드러나고, 복선이 있고, 주제를 스스로 추론한다. 어려운 어휘도 문맥에서 이해한다. 고등 문학 수준의 난해한 상징이나 고어투는 아직 과하다.

**어휘**

| 규칙 | 예시 |
|------|------|
| 중학 교과 어휘 자유롭게 | 질투, 집착, 허영, 운명, 야망 |
| 추상 명사 적극 사용 | 욕망, 고독, 갈등, 위선 |
| 한자어 자유롭게 | 비통함, 숭고함, 역설적으로 |
| 새 어휘 주석 불필요 | 문맥에서 뜻이 드러나게만 배치 |

**L2와의 차이 (추가되는 것)**: 심리 묘사(단순 감정 → 내면 갈등), 복선과 암시, 은유(직유에서 확장), 아이러니.
**L4로 넘어가지 않기**: 고어투 · 문어체 과용, 난해한 상징 중첩, 원전 특유의 문장 구조 그대로 살리기는 L4 에서.

**문장**
- **어절 14개 이하** (대부분의 문장), 복문 · 중문 중심 (단문은 강조 · 리듬용)
- 관형절 · 부사절 포함 가능
- **긴 문장 + 짧은 문장**을 리듬감 있게 교차
  ```
  왕비는 오랫동안 거울 앞에 서 있었다. 거울이 말을 꺼내기도 전에,
  그녀는 이미 답을 알고 있었다. 두려웠다.
  ```
  → 긴 문장으로 장면을 펼치고, 짧은 문장으로 감정을 박는다.

**서술**
- **내면 심리 묘사**: 감정이 왜 생겼는지, 어떻게 변하는지 보여 준다. 감정 이름 나열 금지
  ```
  ❌ 왕비는 질투심을 느꼈다.
  ✅ 왕비는 거울의 대답을 듣는 순간, 가슴 깊은 곳에서 무언가가 무너지는 것을 느꼈다.
     수십 년간 가꿔온 자신의 아름다움이 한 소녀에게 빼앗겼다는 사실이
     도저히 받아들여지지 않았다.
  ```
- **복선 · 암시**: 결말을 미리 암시하는 장면 1~2개. 직접 말하지 않고 행동 · 분위기로 전달
  ```
  ✅ "그 웃음에는 무언가 불길한 것이 담겨 있었다."
  ✅ "사과는 유난히 붉고 탐스러웠다. 너무 완벽해서 오히려 이상할 정도로."
  ```
- **은유**: 직유(~처럼)에서 벗어나 자유롭게
  ```
  ✅ "질투는 그녀의 마음속에서 서서히 독이 되어갔다."
  ```

**구조**
- 1문단 = 5~8문장, 1챕터 = 8~12문단
- 서술 + 심리 묘사 + 대화를 균형 있게 배치
- 챕터 끝: 미해결 긴장감 또는 반전 암시

**작성 시 추가 점검**: 초고 완성 후 심리 묘사가 빠진 곳을 채우고, 복선 · 암시가 1~2개 들어갔는지, 긴 문장 뒤에 짧은 문장이 오는지 본다.

**체크리스트**
- [ ] 챕터 분량 1,400~2,000자
- [ ] 어절 14개 이하 (대부분의 문장)
- [ ] 내면 심리 묘사 포함 (감정 이름 나열 금지)
- [ ] 복선 또는 암시 1~2회
- [ ] 긴 문장 + 짧은 문장 리듬 교차
- [ ] 은유 1개 이상
- [ ] KRIN 점수 650~820 범위
- [ ] 중학 교과 어휘 수준

**예시 (백설공주 L3)**
```
왕비는 마법 거울 앞에 섰다. 거울과 마주하는 일은 언제나 두려운 의식이었지만,
그녀는 멈출 수가 없었다. 아름다움에 대한 확인 없이는 하루를 시작할 수 없었다.
"거울아, 세상에서 가장 아름다운 사람이 누구냐?"
잠시 침묵이 흘렀다. 그 짧은 순간이 왕비에게는 영원처럼 느껴졌다.
"왕비님, 그것은 백설공주입니다."
왕비의 표정이 굳었다. 수십 년간 쌓아온 자부심이 단 한 문장으로 산산조각
났다. 질투는 처음에는 차갑게, 이내 뜨겁게 그녀의 온몸을 타고 흘렀다.

그녀는 천천히 고개를 돌렸다. 창밖으로 보이는 정원이 유독 밝고 화창했다.
오늘 같은 날, 그녀는 가장 끔찍한 결정을 내리게 될 것이었다.
```
- 심리 묘사 "수십 년간 쌓아온 자부심이 단 한 문장으로…" ✅ / 은유 "질투는 차갑게, 이내 뜨겁게 흘렀다" ✅ / 복선 "오늘 같은 날, 가장 끔찍한 결정을…" ✅ / 리듬: 긴 문장 + "잠시 침묵이 흘렀다" ✅

### 4.4 L4 — 고등학생 (KRIN 800~1,050 · 2,000~2,800자)

**독자 이미지**: 고등학교 문학 수업에서 읽는 단편소설이나 원전 발췌문. 어렵고 낯선 어휘도 스스로 해석하고, 상징과 주제를 분석한다. 원전의 시대적 맥락과 문체를 경험하는 것 자체가 목적이다.

**어휘**

| 규칙 | 예시 |
|------|------|
| 고등 수준 + 원전 어휘 | 야망, 비루함, 숙명, 아이러니, 역설 |
| 문학적 표현 허용 | 고어투, 문어체 부분적 허용 |
| 어휘가 독해 과제가 되어도 됨 | 독자가 사전을 찾으며 읽는 것을 전제 |
| 원전 번역 어휘는 최대한 살리기 | 원전이 한국 고전이면 고어 어미 부분 허용 |

**L3와의 차이 (추가되는 것)**: 원전의 문체 · 어조 재현, 복잡한 내포절 · 도치 구문, 서술자 시점 · 거리감의 의식적 조절, 열린 결말, 시대적 · 문화적 맥락을 텍스트에 녹이기.

**문장**
- **어절 18개 이하** (제한보다 호흡 유지가 우선), 원전의 문장 구조 재현 가능
- 단문은 극적 효과를 위해 전략적으로만
- 문단 호흡이 끊기지 않게 (긴 문단도 허용)
  ```
  ✅ 그녀가 원했던 것은, 아름다움 그 자체가 아니라,
     아름다움을 통해 확인받고 싶었던 자신의 존재였는지도 몰랐다.

  ✅ 사과를 손에 쥔 순간, 백설공주는 — 그것이 독이라는 사실을
     어디선가 알고 있었을지도 모르지만 — 한입 베어 물었다.
  ```

**서술**
- **심리 · 상징 · 주제 의식**: L3의 심리 묘사에서 한 단계 더 나아가 **주제와 연결되는 심리**를 쓴다. 독자가 "이 장면이 무엇을 말하는가"를 스스로 묻게 한다
  ```
  ❌ 왕비는 질투심 때문에 백설공주를 미워했다.
  ✅ 왕비가 백설공주를 증오한 것은 단순한 질투가 아니었다.
     그것은 젊음에 대한 공포, 시간 앞에서의 무력감, 그리고
     아름다움 외에 자신을 정의할 무언가를 끝내 찾지 못한
     자의 분노였다.
  ```
- **서술자의 거리감**: 밀착(자유간접화법)과 거리(3인칭 관찰자) 중 의식적으로 선택
  ```
  [밀착 — 자유간접화법]
  왕비는 거울을 바라보았다. 왜 이런 물음을 던지는 것인가.
  그 답이 두렵다면, 처음부터 묻지 말았어야 했다.

  [거리 — 관찰자]
  왕비는 거울 앞에 오랫동안 서 있었다. 그녀가 무슨 생각을
  하는지, 아무도 알 수 없었다.
  ```
- **열린 해석**: 결말이나 핵심 장면에서 독자가 스스로 의미를 채우게 한다
  ```
  ✅ "그 사과가 독인지 알면서도 먹었을까, 아니면 정말 몰랐을까.
     그것은 이 이야기가 끝난 후에도 여전히 물음으로 남는다."
  ```

**구조**
- 1문단 제한 없음, 1챕터 2,000~2,800자
- 서술 · 심리 · 대화 · 묘사가 유기적으로 섞인다
- 챕터 끝: 주제적 여운 또는 다음 챕터로의 긴장감

**체크리스트**
- [ ] 챕터 분량 2,000~2,800자
- [ ] 원전 문체 · 어조와 유사한 어조
- [ ] 심리 묘사가 주제 의식과 연결됨
- [ ] 서술자 시점 · 거리감 일관성
- [ ] 상징 또는 열린 해석 여지 포함
- [ ] 시대적 · 문화적 맥락이 텍스트 안에 녹아 있음
- [ ] 고등 교과 + 원전 수준 어휘
- [ ] KRIN 점수 800~1,050 범위

**예시 (백설공주 L4)**
```
왕비가 거울 앞에 선 것은, 단순한 허영의 의식이 아니었다.
그것은 매일 아침 자신의 존재를 확인하는, 그녀만의 방식이었다.
아름다움은 그녀가 세상과 맺은 유일한 계약이었고, 그 계약이
유효한 한 그녀는 안전했다.

"거울아, 세상에서 가장 아름다운 사람이 누구냐?"

침묵. 그 짧은 침묵 속에서 왕비는 무수한 가능성을 상상했다.
거울이 자신의 이름을 부르기를 기다리는 것인지, 아니면
이미 알고 있는 답을 직시하지 못하는 것인지 — 그 경계는
언제나 모호했다.

"왕비님, 그것은 백설공주입니다."

왕비는 움직이지 않았다. 분노도, 눈물도 없었다. 다만 무언가
거대한 것이 무너지는 소리가, 아무도 들을 수 없는 곳에서
울렸다. 아름다움만으로 살아온 삶이 그 한 문장으로 해체되었다.

그녀가 독사과를 만들기로 결심한 것은 질투 때문이 아니었다.
그것은 생존이었다.
```
- 원전 어조: 고어투 없이도 문학적 어조 유지 ✅ / 심리 + 주제 연결 "아름다움은 세상과의 계약" ✅ / 서술자 거리: 자유간접화법과 관찰자 시점 교차 ✅ / 열린 해석 ✅ / 상징 "무너지는 소리" ✅

## 5. 목차 · 장면 구성 가이드

### 챕터 수
| 작품 유형 | 권장 챕터 수 |
|-----------|-------------|
| 단편 동화 (원전 1~3장) | 3~5챕터 |
| 중편 소설 (원전 5~15장) | 6~10챕터 |
| 장편 (원전 15장+) | 10~15챕터 (MVP에서 일부만) |

### 챕터 구조 원칙
- 각 챕터는 **하나의 사건 또는 장면 묶음**으로 구성
- 시작: 장면 배경 설정
- 중간: 핵심 사건 전개
- 끝: 다음 챕터로 넘어가는 연결 or 미해결 긴장감

### 장면 목록 (scene_list)
- 챕터마다 3~7개. 한 장면 = 한 문장으로 쓴 사건 ("이몽룡이 방자와 광한루에서 경치를 감상함")
- `type`: `배경` · `사건` · `갈등` · `절정` · `복선` · `결말`
- 레벨과 무관하게 **한 챕터에 하나**다 — 네 레벨 파일에 같은 scene_list 가 들어간다

```json
"scene_list": [
  { "id": 1, "scene": "이몽룡이 방자와 광한루에서 경치를 감상함", "type": "배경" },
  { "id": 2, "scene": "그네 타는 춘향을 보고 이몽룡이 반함", "type": "사건" }
]
```

### 레벨 간 일관성
- 동일 챕터의 L1~L4 버전은 **같은 장면**을 다룸 (scene_list 기준)
- 등장인물 이름·지명은 모든 레벨에서 동일하게 통일
- L4 가 가장 풍부하고, 레벨이 내려갈수록 같은 장면을 더 단순하게 쓴다 (L4 를 줄여 쓰는 것이 아니다 — 2장 ②)

## 6. 챕터 파일 형식

- 위치: `ankors/{책제목}/{레벨}/{책제목}_Ch{두 자리}_{레벨}.json` (예: `ankors/춘향전/L1/춘향전_Ch01_L1.json`)
- 원전 텍스트: `ankors/text/`
- 챕터 1개 × 레벨 1개 = 파일 1개

```json
{
  "book_id": "chunhyang",
  "book_title": "춘향전",
  "chapter": 1,
  "chapter_title": "광한루의 만남",
  "level": "L1",
  "status": "draft",
  "reviewed": false,
  "scene_list": [ { "id": 1, "scene": "...", "type": "배경" } ],
  "content": "...(본문)...",
  "intro_static": { },
  "sharing": { },
  "quiz": [ ],
  "debate": [ ],
  "problem_solve": [ ]
}
```

| 단계 | 채우는 필드 |
|---|---|
| ① 설계 | `book_id` · `book_title` · `chapter` · `chapter_title` · `scene_list` |
| ② 본문 | `level` · `content` |
| ⑤ 부가 | `intro_static` · `sharing` · `quiz` · `debate` · `problem_solve` |

## 7. intro_static 작성 기준

읽기 전 안내. 요약 · 인물 · 배경은 레벨 공통이고, 읽기 포인트는 레벨별로 쓴다.

```json
{
  "summary": "이 챕터에서 일어나는 핵심 사건 2~3문장 요약",
  "characters": [
    { "name": "이몽룡", "role": "남원 사또의 아들, 16세. 총명하고 풍류를 즐겨요." }
  ],
  "background": "시대적·공간적 배경 설명",
  "reading_point": {
    "L1": "L1 독자를 위한 읽기 포인트 1문장",
    "L2": "...", "L3": "...", "L4": "..."
  },
  "pre_reading_hook": "읽기 전에 던지는 질문 — 독자의 경험과 이어지게",
  "pre_reading_avoid": ["읽기 전에 말하면 안 되는 내용 (뒤 챕터의 사건 · 결말)"]
}
```

**reading_point 작성 원칙**
- L1: "OO가 왜 ~했는지 생각해봐요" (행동 동기 중심)
- L2: "OO의 감정이 어떻게 변하는지 살펴보세요" (감정 변화)
- L3: "작가가 ~을 통해 무엇을 말하려는지 생각해보세요" (주제 추론)
- L4: "~의 상징적 의미와 원전과의 차이를 비교해보세요" (비판적 독해)

**pre_reading_avoid** 는 AI 가 Intro 대화에서 줄거리를 미리 말하지 않게 막는 목록이다. 이 챕터 뒤에 일어나는 일을 적는다.

## 8. sharing · debate · problem_solve 작성 기준

이 세 단계는 학생과 AI 가 실시간으로 대화한다. 여기서 쓰는 것은 대화가 아니라 **대화의 재료**다 —
챕터마다 주제가 흔들리지 않게 하고, AI 가 책 내용에서 벗어나지 않게 붙잡는다.

### sharing — 나눔
```json
{
  "anchor_quotes": ["본문에서 그대로 가져온 문장 3개 안팎"],
  "questions": [
    { "type": "scene",   "prompt": "이 챕터에서 어떤 일이 있었나요? 차례대로 말해봐요." },
    { "type": "emotion", "prompt": "춘향이 처음 이몽룡 앞에 섰을 때 어떤 기분이었을까요?" },
    { "type": "choice",  "prompt": "여러분이 이몽룡이라면 처음 본 춘향에게 뭐라고 말했을까요?" }
  ]
}
```
- `anchor_quotes`: **그 레벨 본문에 글자 그대로 있는** 문장. 장면이 떠오르는 문장을 고른다
- `questions`: `scene`(무슨 일이 있었나) · `emotion`(인물의 마음) · `choice`(나라면) 각 1개 이상. 말투는 레벨에 맞춘다

### debate — 토론 (챕터당 5개)
```json
{
  "id": 1,
  "type": "A",
  "topic": "첫눈에 반한 사랑이 진짜 사랑일 수 있을까?",
  "pro_label": "진짜 사랑이다",
  "con_label": "아직 사랑이 아니다",
  "background": "이몽룡은 그네 타는 춘향을 한 번 보고 반했어요.",
  "level_hint": { "L1": "...", "L2": "...", "L3": "...", "L4": "..." }
}
```
| type | 성격 | 예 |
|---|---|---|
| A | 작품 속 사건 · 선택에 대한 찬반 | "신분이 다른 사람과 사랑하는 것이 허용되어야 할까?" |
| B | 독자 자신의 경험과 잇는 질문 | "누군가를 위해 큰 약속을 한 적이 있나요?" |
| C | 방법 · 선택을 묻는 열린 질문 | "부당한 명령을 받았을 때 거부하는 방법은 무엇일까?" |

- 기존 도서는 챕터당 A 3개 · B 1개 · C 1개 구성이다
- `background`: 논제가 나온 본문 장면 1~2문장. `level_hint`: 레벨별 생각의 방향 (L1 느낌 → L4 개념 · 해석)

### problem_solve — 문제 해결 (챕터당 5개)
```json
{
  "id": 1,
  "title": "신분 차이 극복",
  "connected_scene": "이몽룡이 기생 월매의 딸 춘향을 사랑하게 되는 장면",
  "intro": "이몽룡은 양반이고 춘향은 기생의 딸입니다. … 여러분 주변에도 서로 다른 환경 때문에 친해지기 어려운 경우가 있나요?",
  "key_question": "신분이나 배경이 다른 사람과 진정한 우정이나 사랑을 나눌 수 있을까? 어떤 노력이 필요할까?"
}
```
- `connected_scene`: scene_list 의 장면과 이어져야 한다
- `intro`: 작품 속 문제 → 독자의 현실 문제로 잇는다. `key_question`: 정답이 하나가 아닌 질문

## 9. 문제은행(quiz) 작성 기준

챕터 파일의 `quiz` 배열에 넣는다. 챕터당 17문항 구성:

| type | 문항 수 | 내용 |
|---|---|---|
| `ox` | 6 | 사실 확인 (함정 문항 포함) |
| `chosung` | 5 | 초성 퀴즈 — 인물 · 장소 · 핵심 단어 |
| `fill_blank` | 3 | 본문 문장의 빈칸 채우기 |
| `who_said` | 2 | 누가 한 말인가 |
| `sequence` | 1 | 사건 순서 맞추기 |

```json
{ "type": "ox", "usage": "game", "level": "L1",
  "question": "이몽룡은 단오날 방자와 함께 광한루에 갔어요.",
  "answer": true, "hint": "광한루에서 경치를 보다가 춘향을 발견했어요.", "difficulty": "easy" }
```
```json
{ "type": "chosung", "usage": "game", "level": "L1",
  "question": "이몽룡이 춘향을 처음 본 곳은?", "answer": "광한루", "chosung": "ㄱㅎㄹ",
  "hint": "남원에 있는 누각이에요.", "difficulty": "easy" }
```

- **정답은 그 레벨 본문에 있어야 한다** — 다른 레벨 본문에만 있는 내용으로 내지 않는다
- 문항의 말투 · 어휘도 그 레벨에 맞춘다
- OX 의 `answer` 는 `true` / `false` 로 쓴다 (서버가 'O' / 'X' 로 바꿔 준다)

### 난이도 기준
| difficulty | 기준 |
|-----------|------|
| easy | 본문에 명확하게 나온 내용 |
| medium | 문맥에서 추론 필요 |
| hard | 세부 내용 기억 필요 |

## 10. 검수 체크리스트

레벨별 본문 체크리스트는 4장(4.1~4.4)의 각 레벨 절 끝에 있다. 여기에는 전 레벨 공통 항목만 둔다.

### 공통 체크 (전 레벨)
- [ ] 레벨별 체크리스트(4.1~4.4)를 통과했다
- [ ] 원전을 입력으로 썼다 (LLM 기억만으로 쓰지 않았다)
- [ ] 네 레벨이 scene_list 의 장면을 모두 다룬다
- [ ] 같은 챕터의 KRIN 이 L1 < L2 < L3 < L4 순서다
- [ ] 등장인물 이름·지명 통일
- [ ] 출력에 장면 제목 · 해설 · 주석이 없다 (4.0 출력 형식)
- [ ] intro_static: summary · characters · background · reading_point(L1~L4) · pre_reading_hook · pre_reading_avoid
- [ ] sharing: anchor_quotes 가 그 레벨 본문에 글자 그대로 있다
- [ ] debate 5개 · problem_solve 5개 · quiz 17문항
- [ ] quiz 정답이 그 레벨 본문만으로 확인된다
