# 『해저 2만 리』 앵커도서 설계

- 원전: 쥘 베른, 『해저 2만 리』 영역본 (Project Gutenberg #164, `ankors/text/twenty_thousand_leagues_en_pg164.txt`) — 1부 23장 + 2부 23장 = 46장
- 책 폴더 `ankors/해저2만리/`, 파일 `L{1..4}/해저2만리_ChNN_{L}.json`, book_id `twenty_thousand_leagues`, book_title `해저 2만 리`
- 분량: L4 기준 약 220쪽(1쪽 ≈ 600자) → **55장**. 장당 L1 500~800 · L2 900~1,300 · L3 1,400~2,000 · L4 2,000~2,800자
- 원작 46장 중 원전 분량이 큰 10개 장(1부 10·21장, 2부 3·4·6·8·13·14·16·21장)을 둘로 나누고, 아주 짧은 2부 23장(결론)은 2부 22장과 합쳤다 → 46 + 10 − 1 = 55장
  - 요청서 예시(1부 15·18장, 2부 18장)는 원전 글자 수가 1만~1만 5천 자로 중간 수준이라 나누지 않고, 대신 원전이 더 긴 2부 4·6·8·14장(1만 6천~1만 9천 자)을 나눴다
- 장면 줄 번호는 설계용으로 원전을 장별로 자른 파일(1행 = "CHAPTER …") 기준이다. 원전 파일에서 해당 장 제목 줄부터 센 줄 수와 같다.

## 2. 서술·말투 원칙 (모든 레벨)

- **1인칭 서술**: 원작처럼 아로낙스 교수가 "나"로 이야기한다. 모든 레벨 동일 (L1 "나는 ~했어요", L2 "나는 ~했습니다", L3·L4 "나는 ~했다").
- 콩세유 → 교수: "주인님", 늘 깍듯한 존댓말 (원작의 3인칭 호칭 버릇을 살려 "주인님께서 원하신다면"). 
- 교수 → 콩세유: L3·L4 하게체("짐을 싸게, 콩세유"), L1·L2 반말.
- 교수 ↔ 네드: 네드는 교수를 "교수님"이라 부르고 거침없는 말투(L3·L4 "~하오/~요" 섞임, L1·L2 해요체). 교수 → 네드: L3·L4 하오체, L1·L2 해요체.
- 네모 선장 → 교수: L3·L4 하오체("~하오", "교수"), L1·L2 해요체. 교수 → 네모 선장: "선장님", 합쇼체/해요체.
- 한 장 안에서 같은 인물의 말투를 바꾸지 않는다.

## 4. 원전 날짜 오류 처리

- 1부 5장(Ch05): 7월 3·6·20·27일, 6월 30일은 1부 4장의 "7월 30일, 출항 3주 뒤"와 모순(영역본 오류). 본문에서는 11월 2일·5일 외의 날짜를 빼고 "얼마 뒤"처럼 쓴다. 위도·경도는 남겨도 된다.
- 1부 19장(Ch20): "1863년 1월 1일"은 오타(1868년). 연도를 쓰면 1868년, 아니면 생략.
- 1부 21장(Ch22): "1월 8일"은 20장과 하루 어긋남 → "다음 날 아침".
- 2부 2장(Ch27): "2월 28일"은 1월 28일의 오기 → 1월 28일로 바로잡거나 생략.
- 2부 19·20장(Ch51·52): 폭풍 5월 18일, 다음 장 5월 15일 시작 — 원전대로 두되 L1·L2 는 "며칠 뒤"로 넘겨도 된다.
- 2부 11장(Ch40): "스피츠베르겐 쪽으로 갔다"는 만류 설명이 섞인 문장 — 노틸러스호가 그리로 간 것처럼 쓰지 않는다.
- 2부 18장(Ch50): 영역 "I owed myself this revenge" 는 프랑스어 원문 뜻대로 "실론에서 네드에게 진 빚을 갚았다"로 쓴다.

## 5. 민감한 내용 처리 원칙

- 원작의 시대적 편견 표현("savages", "negro", "cannibal", 외모·피부 비교, "유럽인은 먼저 공격하지 않는다" 식 문장)은 옮기지 않고 사실만 남긴다. 파푸아 주민 → "섬 주민들", 안다만의 "negroes" → "안다만 제도 사람들".
- 네모 선장의 편견 비판("그들이 다른 사람들보다 더 나쁘오?")은 비하어 없이 뜻을 살린다.
- 죽음·부상·폭력(플로리다호의 시신, 선원의 머리 부상과 산호 묘지, 상어, 대왕오징어에게 끌려간 선원, 군함 격침, 고래 학살): L1·L2 는 자극 없이 사실만("목숨을 잃었어요", "몹시 다쳤어요"), 피·상처 묘사 없음. L3·L4 도 순화(상처 세부 묘사 금지). **사실 자체는 빠뜨리지 않는다**(예: Ch54 군함은 가라앉고 많은 사람이 죽었다는 사실).
- 결말·반전: 네모 선장의 정체(원작에서도 밝혀지지 않음 — 억압받은 자, 복수심, 초상화 정도), 군함 격침(Ch54), 대소용돌이 탈출(Ch55)은 해당 장 전에 드러내지 않는다. 원전에 있는 복선(초상화, 크레타 반란군에 보낸 금, "어떤 폭군이…")만 그 장에서 `복선`으로 둔다.

### Ch01 움직이는 암초
- 원전: 1부 1장 전체 (P1_01 1~43행)
- 날짜·장소: 1866년 7월 20일 오스트레일리아 동해안 5마일 앞바다(거버너히긴슨호), 7월 23일 태평양(콜럼버스호, 사흘 사이 700리그 떨어진 곳), 보름 뒤 대서양 북위 42°15′·서경 60°35′(헬베티아호·섀넌호). 1867년 3월 5일 북위 27°30′·서경 72°15′(모라비안호). 1867년 4월 13일 북위 45°37′·서경 15°12′, 클리어곶에서 300마일(스코샤호) → 리버풀 입항.
- 장면:
  1. (배경) 1866년 여러 배가 고래보다 훨씬 크고 빠른, 빛나는 거대한 물체를 만남
  2. (사건) 거버너히긴슨호 앞에서 그 물체가 150피트 높이로 물기둥 두 줄을 뿜어 올림
  3. (갈등) 괴물이 있느냐 없느냐를 두고 학자와 신문들이 여섯 달 동안 논쟁을 벌임
  4. (사건) 1867년 3월 모라비안호가 지도에 없는 암초에 부딪혀 용골이 부러짐
  5. (절정) 스코샤호 바닥에서 쇠판을 깨끗이 뚫은 이등변삼각형 구멍이 발견됨
  6. (결말) 사람들이 사라진 배들까지 괴물 탓으로 돌리며 바다에서 괴물을 없애라고 요구함

  - 섀넌호·헬베티아호 보고로 몸길이 최소 350피트 추정(가장 큰 고래도 60야드를 넘지 않음)

  - 스코샤호 구멍: 지름 2야드, 두께 1과 3/8인치 쇠판을 뚫고 다시 빠져나간 이등변삼각형

  4. (사건) 아로낙스 교수가 「뉴욕 헤럴드」에 거대한 일각고래일 것이라는 글을 실음
  5. (사건) 미국이 에이브러햄 링컨호를 무장시켰지만 괴물이 두 달 동안 나타나지 않음
